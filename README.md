# 砚藏 iOS

![砚藏横幅](https://raw.githubusercontent.com/yanxu-orange/ST-Orange-Yancang/main/assets/yanzang-release-banner.png)

把故事与角色，好好收藏。

砚藏 iOS 是面向 SillyTavern 的个人资源管理器。你可以在 iPhone 和 iPad 上收纳角色卡和聊天记录，整理角色资料、内嵌世界书和附件，保留导入的原始文件。

## 主要能力

### 角色卡库

- 从本地 PNG、JSON 文件或 URL 导入角色卡，支持导入预览和确认。
- 分目录整理角色卡，按名称搜索、按标签筛选，支持多选管理。
- 编辑角色资料，切换和另存角色卡版本，管理历史头像与附件。
- 为开场白添加备注，按章节连续阅读；可查看和编辑角色卡内嵌的世界书与角色正则。
- 导出角色卡 JSON 或 PNG，也可以分享导入的原始文件。

### 聊天记录库

- 导入本地 SillyTavern JSONL，搜索文件名、查看楼层目录并跳转阅读。
- 调整字体、字号、行距和背景，可用结构标签和阅读正则整理显示内容。
- 切换原文阅读，导出原始聊天记录；阅读设置不改动原文件。

### 备份与恢复

- 在「设置 → 数据管理 → 备份与恢复」导出完整备份或恢复 iOS 端资料。

## 使用边界

本项目仅供个人非商业使用，请勿二次分发或用于商业用途。

请勿使用砚藏保存、转换或传播付费购得、倒卖而来，或来自商业化平台的资源，包括将此类内容转换为 SillyTavern 格式后再行保存。

请尊重每一份创作及其原有的使用边界。愿你珍惜所爱，也祝你天天开心。

## 安装与更新

1. 在 [发布页](https://github.com/yanxu-orange/ST-Orange-Yancang-IOS/releases) 选择版本，从附件下载 IPA。支持 iOS 15.0 及以上。
2. 使用适用于你设备的签名和安装方式安装 IPA。
3. 更新前，可在「设置 → 数据管理 → 备份与恢复」导出完整备份。

## 隐私与许可

导入的资源和管理资料保存在本机。通过 URL 导入时，应用会访问所填写的地址；检查更新时会读取 GitHub 的公开版本信息。

字体许可可在「设置 → 关于砚藏 → 字体与许可」查看。
